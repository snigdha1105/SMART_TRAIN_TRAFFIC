#  Smart Train Traffic Control System

> An AI-powered railway traffic management system that provides real-time conflict detection, delay predictions, what-if simulations, and visual schedule timelines to enhance train scheduling efficiency.


##  Problem Statement

Indian Railways operates **13,000+ trains daily** on shared tracks. When two trains are scheduled on the same section at the same time, it creates conflicts that cascade into delays across the entire network.

Traditional manual scheduling is:
- Slow and reactive
- Prone to human error
- Unable to simulate outcomes before decisions

**This system provides a proactive, AI-driven solution.**

---

##  Features

###  Live Dashboard
Real-time system overview showing total trains, stations, active conflicts, and system status.

###  Conflict Detection Engine
Automatically scans all train schedules and flags trains that are dangerously close to each other on the same section, with auto-suggested fixes.

###  AI Delay Predictor
ML model (Random Forest) predicts expected delay in minutes based on:
- Train type (Rajdhani / Mail / Express)
- Station
- Hour of day
- Day of week
- Peak hour / weekend flags

###  What-if Simulation
Operators can simulate *"What if I delay Train A by X minutes?"* and see the exact ripple effect before making a real decision. Returns SAFE ✅ or UNSAFE ❌ verdict.

### Gantt Chart Timeline
Visual train schedule timeline showing all trains across all stations. Conflict zones are highlighted in red with warning indicators.

##  Getting Started

### Prerequisites
- Python 3.11+
- Node.js 18+
- Git

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/smart-train-traffic.git
cd smart-train-traffic
```

### 2. Setup Backend
```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate

pip install fastapi uvicorn sqlalchemy pandas scikit-learn python-dotenv
python database.py
uvicorn main:app --reload
```

### 3. Train the ML Model
```bash
cd ml
python generate_data.py
python train_model.py
```

### 4. Setup Frontend
```bash
cd frontend
npm install
npm start
```

## How What-if Simulation Works

1. Operator selects a train and inputs a delay amount
2. System applies the delay to all that train's schedule entries
3. Conflict detection engine runs on the modified schedule
4. System returns remaining/new conflicts with SAFE ✅ or UNSAFE ❌ verdict
5. Operator tries different values to find the optimal solution

---

##  How Gantt Chart Works

- Fetches all schedules, trains and conflicts from the API
- Renders a horizontal timeline bar for each train at each station
- Bars are colored uniquely per train
- Conflict zones highlighted in **red** with indicator
- Hover over any bar to see arrival and departure times
